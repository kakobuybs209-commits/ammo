🚀 JAK KORZYSTAĆ:

┌─ KROK 1: Pobierz szablon CSV ────────────────────────────────────┐
│                                                                   │
│  1. Zaloguj się do panelu admina                                 │
│  2. Przejdź do zakładki "Produkty"                               │
│  3. Kliknij przycisk z ikoną importu                             │
│  4. W modalu kliknij link "Pobierz szablon CSV"                  │
│  5. Plik products-template.csv zostanie pobrany                  │
│                                                                   │
└───────────────────────────────────────────────────────────────────┘

┌─ KROK 2: Wypełnij szablon ───────────────────────────────────────┐
│                                                                   │
│  Otwórz plik CSV w Excelu lub notatniku i dodaj swoje produkty  │
│                                                                   │
│  Format kolumn:                                                  │
│  - id         → Unikalny ID (np. 1, 2, 3)                       │
│  - name       → Nazwa produktu                                   │
│  - price      → Cena (liczba, np. 299.99)                       │
│  - currency   → Waluta (PLN, EUR, USD, CNY)                     │
│  - image      → Link do zdjęcia                                  │
│  - category   → Kategoria (Buty, Odzież, etc.)                  │
│  - link       → Link do produktu (Weidian, Taobao)              │
│  - status     → active lub inactive                              │
│  - clicks     → 0                                                │
│  - popular    → true lub false                                   │
│                                                                   │
└───────────────────────────────────────────────────────────────────┘

┌─ KROK 3: Zaimportuj produkty ────────────────────────────────────┐
│                                                                   │
│  1. W modalu importu kliknij "Wybierz plik"                      │
│  2. Wybierz swój wypełniony plik CSV                             │
│  3. System automatycznie wykryje produkty                        │
│  4. Sprawdź liczbę wykrytych produktów                           │
│  5. Kliknij "Rozpocznij Import"                                  │
│  6. Poczekaj na zakończenie                                      │
│  7. Sprawdź wyniki (sukces/błędy)                                │
│                                                                   │
└───────────────────────────────────────────────────────────────────┘

⚠️ CZĘSTE PROBLEMY:

Problem: "Funkcja nie jest dostępna"
Rozwiązanie: Wyczyść cache przeglądarki (Ctrl+Shift+Delete)
            i odśwież stronę (Ctrl+F5)

Problem: "Szablon się nie pobiera"
Rozwiązanie: Sprawdź konsolę (F12) i uruchom diagnose-import.js

Problem: "Import nie działa"
Rozwiązanie: Sprawdź format CSV - użyj szablonu!
